# مبدل و ویرایشگر Pocket Office (نسخه‌ی سرور ۴)

> سرور از چند فایل کنار هم ساخته شده؛ **کل پوشه‌ی `converter` را با هم نگه دار**:
> `pocket_office_server.py`، `po_docx_edit.py`، `po_office_edit.py`، `po_new_file.py`، پوشه‌ی `wordtk` و پوشه‌ی `panel`.
> خط اول اجرای سرور باید `v4.0` را نشان دهد و خط ویرایشگر باید `Editors : Word + Excel + PowerPoint ready` باشد.
> اگر `MISSING` دیدی، یکی از فایل‌ها یا `lxml` کم است (`apt install python3-lxml`).
> پورت پیش‌فرض **۸۵۸۵** است. پنل ویرایش: `http://127.0.0.1:8585/`

## پنل وب (ویرایشگر)
- در مرورگر گوشی `http://127.0.0.1:8585/` را باز کن، یا از اپ: **Export ▸ Edit a copy in the browser…** (فایل باز‌شده را به‌صورت کپی می‌فرستد و پنل را روی همان باز می‌کند)، یا **New Word / Excel / PowerPoint file** در صفحه‌ی اصلی اپ.
- هر زبانه‌ی مرورگر یک نشست ویرایش مستقل است (چندپنجره‌ای)؛ کپی/پیست بین زبانه‌ها کار می‌کند.
- ساخت فایل جدید: همه‌ی ۱۴ نوع OOXML (docx dotx docm dotm، xlsx xltx xlsm xltm، pptx ppsx potx pptm ppsm potm) مستقیم ساخته می‌شوند.
  فرمت‌های odt ods odp rtf doc xls ppt و مشابه با «دوقلوی OOXML» ویرایش و هنگام ذخیره با LibreOffice تبدیل می‌شوند.
  **ساخته نمی‌شوند:** `xlsb` و فرمت‌های قدیمی StarOffice (`sxw stw sxc sxi`).
- ابزارها: ویرایش متن، فونت، پاراگراف، درج/حذف، Find/Replace با پیش‌نمایش، ۱۳ گروه تنظیمات Word (با پیش‌نمایش تأثیر)، شبکه‌ی Excel با فرمول، تنظیم صفحه، Undo، پیش‌نمایش با موتور واقعی چیدمان، ذخیره با راستی‌آزمایی.
- **فایل اصلی هرگز تغییر نمی‌کند**؛ ذخیره = دانلود یک فایل جدید.

## چندپنجره‌ای در اپ
هر فایلی که باز می‌کنی پنجره‌ی مستقل خودش را دارد (برای حالت دو‌پنجره‌ای / شناور اندروید). دکمه‌ی **Open a new window** در صفحه‌ی اصلی و گزینه‌ی **Open this file in a new window** در منوی Export.

## پیش‌نیازهای سرور
`python3`، LibreOffice، `poppler-utils` (برای pdftotext، pdfinfo و **pdftoppm** که تصویر پیش‌نمایش می‌سازد) و `lxml`.
اجرا: `python3 pocket_office_server.py` (روی کامپیوتر: `--lan`؛ کتابخانه‌ی فونت: `--fonts پوشه`).

## عیب‌یابی (اول این را اجرا کن)
روی همان ماشینی که سرور اجرا می‌شود (داخل Debian proot در Termux، یا روی کامپیوتر):
```
python3 po_doctor.py
```
هر چیزی که کم باشد با دستور دقیق نصبش نوشته می‌شود. برای نصب یک‌جای همه‌چیز در Debian/Termux: `sh install_deps.sh`

**پنل در مرورگر گوشی باز می‌شود ولی خطای «The editors need … lxml» می‌دهد** (و در اپ هم «Cannot start editing»):
سروری که روی خود گوشی اجرا می‌شود ماژول `lxml` ندارد. داخل Debian: `apt install -y python3-lxml` و سرور را دوباره اجرا کن.
(اگر سرور را با Python خود Termux اجرا می‌کنی: `pkg install python-lxml`.) خط «Editors» در بالای خروجی سرور باید `ready` شود.
نمایش و تبدیل فایل بدون lxml کار می‌کند؛ فقط ویرایش بسته است.

**اپ به سرور روی کامپیوتر وصل نمی‌شود:**
- `127.0.0.1` یعنی **خود گوشی**، نه کامپیوتر. روی کامپیوتر سرور را با `--lan` اجرا کن: `python pocket_office_server.py --lan`
- آدرسی که سرور بعد از «In the app» چاپ می‌کند (مثلاً `http://192.168.1.20:8585`) را در اپ بنویس: **Converter settings / test** ← Test.
- گوشی و کامپیوتر باید روی یک Wi-Fi باشند (نه داده‌ی موبایل، نه Wi-Fi مهمان با جداسازی دستگاه‌ها).
- ویندوز: وقتی Python برای فایروال سؤال کرد، **Private networks** را اجازه بده.
- همین آدرس را در مرورگر گوشی هم امتحان کن (`http://IP:8585/`)؛ اگر آنجا باز نشد مشکل شبکه/فایروال است، نه اپ.

## ویرایش (اختیاری، فقط وقتی خودت بخواهی)
در حالت عادی هیچ‌چیز ویرایش نمی‌شود. از منوی «Export / Edit» گزینه‌ی **Edit a copy in the browser…** را بزن.
- فایل‌های موجود: فقط Word (`.docx .docm .dotx .dotm`)، Excel (`.xlsx .xlsm .xltx .xltm`) و PowerPoint (`.pptx .pptm .ppsx .ppsm .potx .potm`). بقیه‌ی فرمت‌ها فقط نمایشی‌اند (بازنویسی با LibreOffice می‌تواند به سند آسیب بزند).
- **فایل اصلی هرگز تغییر نمی‌کند.** ویرایش روی یک کپی است و فقط با «Save as…» فایل جدید ساخته می‌شود.
- **قبل از شروع گزارش می‌دهد** (و همان را در Termux چاپ می‌کند): امضای دیجیتال، ماکرو، تغییرات ردیابی‌شده، فیلدها،
  کادر متن و شکل، نمودار و SmartArt، چند بخش، محافظت سند (در این حالت ویرایش بسته است) و غیره.
- روش کار «جراحی روی XML» است: فقط پاراگراف‌هایی که تغییر می‌دهی عوض می‌شوند. همه‌ی بخش‌های دیگر فایل
  (سبک‌ها، تم، نمودار، تصویر، ماکرو، سرصفحه و پاصفحه، فونت‌های جاسازی‌شده) بایت‌به‌بایت کپی می‌شوند.
- پاراگراف‌هایی که چیزی غیرساده دارند (عکس، فیلد، پاورقی، کادر متن، تغییر ردیابی‌شده، کنترل محتوا، فرمول) **قفل** می‌شوند:
  دیده می‌شوند ولی ویرایش یا حذف نمی‌شوند.
- ابزارها: متن، فونت (نام، اندازه، bold/italic/underline، رنگ، روی بخش انتخاب‌شده یا کل پاراگراف)، پاراگراف
  (تراز، راست‌به‌چپ، فاصله‌ی خطوط، فاصله قبل و بعد، تورفتگی)، درج و حذف پاراگراف، درج و حذف ردیف جدول،
  تنظیم صفحه (اندازه‌ی کاغذ، جهت، حاشیه‌ها)، Undo، پیش‌نمایش با موتور واقعی چیدمان.
- **قبل از ذخیره راستی‌آزمایی می‌شود:** فقط یک بخش عوض شده، XML سالم است، پاراگراف‌های قفل‌شده دقیقاً همان‌اند،
  LibreOffice فایل را باز می‌کند. نتیجه هم در Termux ثبت می‌شود (و در فایل `~/.pocket_office/edit_log.txt`).
- تست‌نشده: Microsoft Office واقعی (فقط LibreOffice در دسترس بود)، پنل روی مرورگر واقعی گوشی، و اجرای اپ روی دستگاه. فایل‌های مهم را بعد از ذخیره یک بار در Office باز کن.

## فرمت‌های پشتیبانی‌شده
- **Word:** docx docm dotx dotm doc dot odt ott fodt rtf sxw stw
- **Excel:** xlsx xlsm xltx xltm xlsb xls xlt ods ots fods sxc
- **PowerPoint:** pptx pptm ppsx ppsm potx potm ppt pps pot odp otp fodp sxi
- **فایل متنی** (txt، py، sh، json، md، csv و هر فایل متنی دیگر): داخل خود اپ و بدون مبدل در ویرایشگر ساده باز می‌شود.
  ویرایش همیشه به‌صورت «ذخیره‌ی یک کپی» است و فایل اصلی تغییر نمی‌کند.
- لیست کامل فرمت‌های سرور: `http://127.0.0.1:8585/formats`


اپ برای نمایش دقیق صفحه‌ها (اندازه‌ی A4، حاشیه‌ها، textbox و جدول‌های شناور، تنظیمات چاپ Excel) فایل را به
**LibreOffice** می‌دهد و PDF واقعی را نمایش می‌دهد. LibreOffice باید روی گوشی (داخل Termux) یا روی یک کامپیوتر
در همان شبکه اجرا شود. من نصب را روی گوشی تست نکرده‌ام؛ اگر مرحله‌ای خطا داد، متن خطا را بفرست.

## روش ۱ – روی خود گوشی (Termux + Debian)
۱. Termux را نصب کن (از F-Droid یا GitHub) و یک بار اجرا کن:
```
termux-setup-storage
pkg update && pkg install proot-distro
proot-distro install debian
```
۲. وارد Debian شو (پوشه‌ی حافظه‌ی گوشی به نام /sdcard در دسترس قرار می‌گیرد):
```
proot-distro login debian --bind /storage/emulated/0:/sdcard
```
۳. داخل Debian (حدود ۱.۵ تا ۲ گیگابایت دانلود):
```
apt update
apt install -y python3 python3-lxml poppler-utils libreoffice-writer libreoffice-calc libreoffice-impress \
  fonts-crosextra-carlito fonts-crosextra-caladea fonts-liberation fonts-noto-core
```
۴. پوشه‌ی `converter` را (کامل) در حافظه‌ی گوشی داخل پوشه‌ی `PocketOffice` بگذار و اجرا کن:
```
python3 /sdcard/PocketOffice/converter/pocket_office_server.py
```
۵. اپ Pocket Office را باز کن و فایل را انتخاب کن. (آدرس پیش‌فرض اپ: `http://127.0.0.1:8585`)
   اولین تبدیل ممکن است تا یک دقیقه طول بکشد.
   برای اینکه اندروید Termux را نبندد، قبل از ورود به Debian یک بار در Termux بزن: `termux-wake-lock`

## فونت‌ها (نسخه‌ی ۳ سرور: فقط فونت‌های لازم بارگذاری می‌شوند)
پوشه‌ی `PocketOffice/Fonts` در حافظه‌ی گوشی حالا یک «کتابخانه‌ی فونت» است و می‌تواند هزاران فونت داشته باشد.
سرور یک بار نام خانواده‌ی همه‌ی فونت‌ها را ایندکس می‌کند (اولین اجرا کمی طول می‌کشد، بعد از آن فقط فایل‌های
جدید خوانده می‌شوند) و برای هر فایل Office فقط فونت‌هایی را که همان فایل استفاده می‌کند در اختیار LibreOffice می‌گذارد.
- اگر فونت جدید به پوشه اضافه کردی، خودکار شناسایی می‌شود (یا در مرورگر گوشی `http://127.0.0.1:8585/reindex` را باز کن).
- در لاگ سرور برای هر فایل می‌بینی چه فونت‌هایی لازم بود، چندتایشان بارگذاری شد و کدام‌ها در هیچ‌جا نبود.
- مسیر دیگری برای کتابخانه: `python3 pocket_office_server.py --fonts /path/to/fonts` (چند بار هم می‌شود نوشت).
- حالت قدیمی (همه‌ی فونت‌ها برای هر فایل، فقط برای عیب‌یابی): `--fonts-all`.
- روی ویندوز LibreOffice خودش از همه‌ی فونت‌های نصب‌شده‌ی ویندوز استفاده می‌کند و این بخش لازم نیست.

## روش ۲ – روی کامپیوتر (Windows / Linux / Mac)
LibreOffice و Python را نصب کن، `soffice` را در PATH بگذار (در ویندوز: `C:\Program Files\LibreOffice\program`)
و `pdftotext` (بسته‌ی poppler) را برای خروجی TXT نصب کن. سپس:
```
python pocket_office_server.py --lan
```
در اپ، آدرس را به `http://IP-کامپیوتر:8585` تغییر بده (گوشی و کامپیوتر در یک Wi-Fi باشند).
هشدار: این سرور رمز ندارد؛ فقط روی شبکه‌ی امن اجرا کن.
